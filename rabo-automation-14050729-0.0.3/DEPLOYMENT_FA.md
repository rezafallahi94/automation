# راهنمای انتشار رابو 0.0.4

## نکته حیاتی
این مخزن سورس کامل React و PHP را دارد اما **انتشار خودکار فعلاً فقط فرانت‌اند** است. علت: بک‌اند 0.0.4 از جدول‌های `rabo_*` استفاده می‌کند که ممکن است با دیتابیس نصب‌شده قبلی (`users`, `projects`, ...) ناسازگار باشد. همچنین منطق ورود، حساب پیش‌فرض و مهاجرت داده هنوز نیاز به تست امنیتی دارند. **کپی خودکار PHP فعال نشده است** تا دیتابیس و حساب‌های موجود خراب نشوند.

## نصب در GitHub
تمام محتویات این پوشه (از جمله `.github` و `.cpanel.yml`) را به ریشه مخزن `automation` منتقل کن. پوشه تو در تو نساز. در GitHub Settings > Actions > General، اجازه Read and write permissions را برای Actions فعال کن.
بعد از Push، اجرای GitHub Actions را بررسی کن. اگر Build موفق شد، پوشه `deploy-ready` خودکار به مخزن Commit می‌شود.

## انتشار در cPanel
Repository Path: `/home/raboau/repositories/automation`
در cPanel > Git Version Control > Manage > Pull or Deploy، ابتدا Update from Remote سپس Deploy HEAD Commit بزن.
فقط `index.html` و فایل‌های `assets` و استاتیکِ مورد نیاز منتشر می‌شوند. دیتابیس، `uploads`، `config.php` و PHPهای هاست بازنویسی نمی‌شوند.

## سازگاری دیتابیس
در نسخه قبلی که روی هاست نصب شد، schema.sql جدول‌های بدون پیشوند داشت. نسخه 0.0.4 ساختاری با پیشوند `rabo_` دارد. **این schema را روی دیتابیس زنده Import نکن** تا نگاشت داده، مهاجرت و سازگاری API بررسی شود. هیچ رمز فعلی را در GitHub قرار نده.

## تکمیل Full Stack
برای آپدیت PHP نیز باید ابتدا احراز هویت پیش‌فرض حذف شود، از `APP_SECRET_KEY` امن و اختصاصی استفاده شود، نوع جداول با دیتابیس هاست سازگار شود، و APIها در محیط تست بررسی شوند. فایل‌های PHP داخل این مخزن برای ادامه توسعه موجودند اما هنوز آماده انتشار خودکار عمومی نیستند.
