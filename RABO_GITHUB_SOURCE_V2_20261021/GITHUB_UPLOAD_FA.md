## آپلود در GitHub
1. مخزن Private بسازید.
2. این ZIP را در کامپیوتر Extract کنید.
3. Add file → Upload files را باز کنید.
4. محتویات پوشه را آپلود کنید، نه خود ZIP یا پوشه بیرونی را.
5. package.json و src باید در ریشه مخزن دیده شوند.
6. فایل‌های نقطه‌ای .gitignore و .env.example را هم اضافه کنید؛ اگر ویندوز نمایش نمی‌دهد نمایش فایل‌های مخفی را فعال کنید.
7. Commit changes را بزنید.
